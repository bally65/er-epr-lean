## 0. 一句話結論

十個角色對「洞在哪裡」的定位全部收斂到**同一個地方**，只是用了不同的話說：

| 角色 | 洞的說法 |
|---|---|
| 全像物理 | AdS/CFT 字典本身：Hartle–Hawking 態 = 邊界 CFT 態 |
| 量子資訊 | 「連通 ⇒ 糾纏」（秩 ≥ D^{min-cut}）對給定網路為假，只對一般張量成立 |
| 空洞獵人 | Z_重力(β) = Tr e^{−βH} |
| 量子統計 | 「視界光滑 ⇒ 場關聯週期 β ⇒ KMS_β」中間需要彎曲時空上的量子場 |
| 張量網路 | 連續極限：格距 → 0、D → ∞ 後區域代數是 type III，沒有密度矩陣 |
| 廣相幾何 | E = M 加態密度 e^{4πM²}：M 是連續幾何參數，H 是有限維矩陣 |
| 數學結構 | 實例 X₁ 的 KMS 代數必須是場代數；兩側只共享 (β, α, σ) 這個 reduct |
| 科學哲學 | 「這個矩陣系統 = 這個時空」是對應規則，不是數學物件之間的映射 |
| 文獻稽核 | 全鏈沒有任何一個等號在文獻裡是定理，全是 proposal／conjecture |

所以設計目標不是填洞，而是**把兩側各自往中間多走幾站，讓洞縮到一個明確的位置，並用一條可證的不可能定理標出它的形狀**。

## 1. 提議的鏈

```
ER ═ X₀ ═ X₁ ═╣ h ╠═ X₂ ═ X₃ ═ X₄ ═ EPR
```

| 站 | 數學物件 | 等號類型 | 現況 |
|---|---|---|---|
| ER | Kruskal 座標 (U, V)、度規係數 F(UV)、因果結構 | — | ER-1 已做 |
| X₀ | 同一個 Schwarzschild 的三張圖（Kruskal／各向同性／r）之間的座標變換恆等式 | **定理** | 未做（K1） |
| X₁ | 歐氏截面：笛卡兒圖 (X, Y) 下度規分量在原點可連續延拓 ⇔ β = 8πM | **定理** | ER-3 只做了弱版（比值極限） |
| **h** | 「這個幾何的量子態 = 某個 (H, β) 的 KMS 態」 | **不可形式化**；只能寫成假設 `(h : …)` | 永遠留白 |
| X₂ | KMS_β 態：跡為 1 且滿足 KMS 條件 ⇒ 等於 Gibbs(H, β) | **定理**（逆向才有內容） | 未做 |
| X₃ | TFD：歐氏演化 e^{−βH/2} 準備的純化；純化唯一到 B 側么正；modular 流 | **定理** | T2、T2d 已做，其餘未做 |

兩側各自的「=」全是定理。**h 是唯一的洞**，而且不能再拆：再插中繼站只會拆出更多對應規則，不會拆出定理（角色 8 的「稀釋檢驗」）。

## 2. 洞的形狀：一條可證的不可能定理

角色 7 與角色 8 **各自獨立**推出同一條，主線驗算通過：

> 對任何有限維 Hermitian H，β ↦ S_vN(gibbs H β) 在 β > 0 上**不增**（dS/dβ = −β·Var_β(H) ≤ 0）。
> Schwarzschild 的熵 S = 4πM²、β = 8πM，寫成 β 的函數是 S = β²/16π，**嚴格遞增**。
> 所以不存在任何單一有限維 H，使 TFD(β) 的熵在任何正長度的 β 區間上等於黑洞熵。

含義：
- 「黑洞 = 固定有限維系統的正則系綜」這種識別法**一開始就排除**，剩下只能走微正則或無限維。
- 在單一 β 點上，任何 H 都能調到 S 相等，所以「單點熵相等」沒有內容。
- 限定：只對漸近平坦的 Schwarzschild 成立（比熱為負）。AdS 大黑洞比熱為正，此定理不適用。

這條定理的價值是把 h 的位置釘死。它會寫進庫裡，標題就叫不可能定理，不叫別的。

## 3. 統一骨架：KMSPair（角色 9）

### 3.1 為什麼純群作用不夠

主線一開始回答使用者「要不要用群論」時提的 ℝ ⋊ Z₂ 骨架，角色 9 證明是**空的**：任何有不動點的 ℝ ⋊ Z₂ 集合都是它的模型。群作用只能當介面檢查（它會逼出「Z₂ 必須配轉置，不是 swap」）。要有內容，必須加上**態**與**非退化性**。

### 3.2 結構草稿

```lean
structure KMSPair (𝒜 : Type*) [Ring 𝒜] [Algebra ℂ 𝒜] where
  α      : ℂ → 𝒜 ≃ₐ[ℂ] 𝒜          -- 複化的流
  α_add  : ∀ z w, α (z + w) = (α z).trans (α w)
  ω      : 𝒜 →ₗ[ℂ] ℂ               -- 態
  ω_one  : ω 1 = 1
  ω_nondeg : ∀ x, (∀ a, ω (a * x) = 0) → x = 0
  ω_inv  : ∀ t : ℝ, ∀ a, ω (α t a) = ω a
  β      : ℝ
  kms    : ∀ a b, ω (a * α (β * Complex.I) b) = ω (b * a)
  σ      : 𝒜 ≃ₐ[ℂ] 𝒜ᵐᵒᵖ            -- 反自同構（對應轉置）
  σ_α    : ∀ t : ℝ, σ ∘ α t = α (-t) ∘ σ   -- 示意；精確型別待工程定
```

### 3.3 結構層級的實質定理

`tracial_iff_period`：非退化加 KMS ⇒（∀ a b, ω(ab) = ω(ba)）⇔ α_{iβ} = id。證明三行（主線驗算通過）。

推論：
- ER 側的代數是**交換的**（座標函數），所以 α_{iβ} = id 必成立：β 被剛性釘在週期格上。
- EPR 側 α_{iβ} = id ⇔ Gibbs 態是純量 ⇔ H 是純量。H 非純量時不成立：β 自由。
- **所以「溫度」那一行的等號是單向特化**：ER 決定 β = 8πM，EPR 把它吃進去。兩側不等價。

### 3.4 不同構定理

從 M₂(ℂ) 到任何交換整環不存在保 1 的環同態（E₁₁ = E₁₂E₂₁、E₂₂ = E₂₁E₁₂、E₁₁E₂₂ = 0 ⇒ 1 = 0）。所以兩側**不是**同一物件的兩種表示，只共享 (β, α, σ)。這把角色 8 的「同構 vs 類比」分類落到數學上：中間那一欄最多是「共享 reduct」，到不了同構。

## 7. 對外措辭（角色 8、10）

可以用：
- 「兩側各自的定理，加一個**命名的識別假設** h」（條件定理）。
- 「玩具字典」。
- docstring 句式：「本定理是 [Maldacena 2003, §2] 中某陳述的有限維玩具類比，其物理對應需假設 h。」

絕對不能用：
- 「證明／形式化／驗證了 ER=EPR」、「ER=EPR 的 Lean 證明」。
- 「機器檢查的物理」；「零 sorry、標準三公理，所以物理成立」（三公理只擔保數學）。
- 「只剩一個假設」而不說明 h 的強度（它可能就是整個猜想）。
- 「首次」「首創」。

不可能性邊界聲明（角色 8 草稿，主線採用）：

> 本庫證明的是：在顯式座標與有限維矩陣這兩個數學模型內，若識別假設 h 成立，則其餘等式成立；h 本身不是定理。h 一邊談矩陣、一邊談時空，把「這個矩陣系統」當成「這個時空」需要的是一條對應規則，不是兩個數學物件之間的映射，所以它沒有「可證」的真假，只有與世界及量子重力理論是否相符。這不是 Lean 的限制：紙筆、Coq、Isabelle 都只能證形式系統內的陳述。能被檢驗的是 h 的推論（例如 §2 的不可能定理），不是 h 本身。

## 8. 文獻層級（角色 10，核對等級已標）

- **全鏈沒有任何一個等號在文獻裡是定理**。Maldacena 2003 原文用 "proposal"；RT 2006 用 "proposed"；Maldacena–Susskind 2013 用 "conjecture"；Van Raamsdonk 2010 是 essay 與論證。
- 幾個對本庫有直接影響的細節：
  - Maldacena 2003 腳註 1：某引文的態公式差因子 2，與「黑洞溫度是兩倍」的舊錯有關。本庫 T2 的 e^{−βH/2} 約定要與 ER-3 的 β = 8πM 對齊（S1 做完就能機器檢查）。
  - Maldacena–Susskind 腳註 4 自承 "maximally entangled" 是 abuse of language，TFD 的約化態是熱態不是單位陣。本庫不得稱 TFD 最大糾纏。
  - Van Raamsdonk 寫 Tr₂ = ρ 時沒有轉置，因為他在能量基底下算；本庫的「B 側是轉置」是基底層級的事實，**不是文獻結論**，docstring 不得引他。
  - Swingle 2009/2012 給的是**上界**（HNQTWY 引言明確這樣歸類）；等號是 HNQTWY（D → ∞ 機率陳述）與 HaPPY（完美張量、「許多情形」）。本庫的秩上界對應 Swingle，不對應 RT。
  - Hartle–Hawking 1976 是場的 Green 函數週期；本庫 ER-3 是度規的幾何陳述。兩者等價是常識但不是同一個陳述，docstring 要分開寫。

## 10. 候選站 X₁′：類比重力的核心定理（2026-10-24 追加）

討論「怎麼對接實驗」時定位出來的理論項目。實驗（超冷原子聲學視界：Steinhauer 2016、2019；水槽：Weinfurtner 2011）量到的是 Hawking 推導的**運動學核心**，它不需要 Einstein 方程、不需要真的重力，所以是純數學、可形式化：

> 一維波動方程式，加一個視界（流速越過波速的點），則視界兩側模態的 Bogoliubov 變換係數滿足 |β_ω|²/|α_ω|² = e^{−2πω/κ}，出射態是溫度 κ/2π 的熱態（KMS）。

- 類型：**定理**（分析，不是座標代數）。
- 位置：它就是角色 3 定位的洞的**上半**「視界 ⇒ KMS_β」。做完之後，溫度那一行的 ER 側從「錐角條件」升級成「有視界就有這個溫度」，洞只剩下半「這個熱態 = 黑洞微觀態（S = A/4 的等號）」，不能再短。
- 成本：中高。需要模態函數的解析延拓與 Gamma 函數積分（mathlib 有 `Real.Gamma`／`Complex.Gamma`，Bogoliubov 係數的標準算法走 ∫ x^{iω/κ−1} e^{−ikx} 類的積分，mathlib 現況未查）。先做 1+1 維 Rindler 版（κ 固定、沒有位勢），黑洞版等 Rindler 版過了再估。
- 負控制：κ → 0（沒有視界）時係數比 → 1 或 0，不是熱譜；兩側模態寫錯對易關係時不守恆。
- 空洞形狀：把「熱態」定義成那個係數比，然後證它等於那個係數比。防法：KMS 條件用 `KMS.lean` 既有的 `IsKMS` 寫，不另定義。
- 文獻：Unruh 1981（類比重力的起點）、Hawking 1975、Steinhauer 2016 Nature Physics／2019 Nature（卷頁未核對）。

排序：B3、B4 之後；若使用者想往「有實驗對照的定理」走，這是唯一一條。

**2026-10-24 已做**（`ErEpr/GammaRotation.lean`、`ErEpr/Unruh.lean`）：見 README 的 X₁′ 一節與 `DESIGN.md` §22。偏離：熱態沒有用 `IsKMS`（有限維）寫，改用獨立定義的諧振子平均佔據數；正則對易關係仍是假設。

## 11. 溫度作為唯一的共同尺：S5 的升級理由（2026-10-24 追加）

使用者觀察：溫度像是宇宙量能量的尺。對照本庫：β 是字典表上**唯一同時出現在兩欄的同一個實數**（`hawking_beta` 與 `gibbs`／`IsKMS`）。但目前它只是「同一個參數值」，不是「同一個定義」：ER 側 `first_law_area` 把 β = dS/dM 當假設 `hS`，EPR 側 β 是 Gibbs 態的參數。

S5（§5.2）做完後，EPR 側也會有 β = dS/dE 的**定理**（`dS/dβ = β·dE/dβ`，等價於 β 是熵對能量的斜率）。那時溫度那一行從「兩邊恰好用同一個數」升級成「兩邊用同一個定義：熵對能量的斜率」，這才是真正的共同尺。

不可能定理（§2）與此一致：正則系綜的尺對不上黑洞，因為斜率符號相反；所以尺必須是微正則的 dS/dE，不是 Gibbs 參數。

物理背景（只進 docstring）：Hawking 溫度 T = ħκ/(2πk_B c) 是唯一讓 ħ、c、G、k_B 共用一個數的公式；k_B T/ħ 是頻率；Unruh a = 2πT；Tolman–Ehrenfest 溫度隨重力紅移；Connes–Rovelli 溫度 = modular 時間／幾何時間。

排序：與 X₁′ 並列，在 B3、B4 之後；S5 的 Klein 不等式部分可先不做，只做 `dS/dβ = β·dE/dβ`（由 `NoGo.lean` 的 `hasDerivAt_gibbsEntropyFn` 與 N/Z 的導數直接得，成本易）。
